Download Infera

Pick your device. You'll need a pairing code from the dashboard (Contribute a device → Get pairing code). These are beta builds, refreshed automatically with every update.

Android phone

Download APK
  1. Open the downloaded file and allow your browser to install apps.
  2. Enter this site's address and your pairing code.
  3. Paste a small model link (e.g. Qwen3 0.6B .gguf), benchmark, then Start earning.

Runs only while charging, on Wi-Fi, above 50% battery.

Windows

Download for Windows

Or in PowerShell:

irm /install.ps1 | iex
  1. Install Ollama.
  2. Open a new terminal: infera setup CODE. NVIDIA GPUs with 8 GB+ also get text to speech, text to video and fast transcription (a few GB download).

First run: Windows shows a blue box. Click More info → Run anyway (the build isn't code-signed yet).

Mac and Linux

curl -fsSL /install.sh | sh

Linux direct download: infera-linux-x64.tar.gz. Mac builds are coming; until then the script shows how to build it on a Mac in a few minutes.

Mac: if macOS blocks the file, run xattr -d com.apple.quarantine ./infera once.

Set up a computer in one command

Get a code on the dashboard (Contribute tab, Get pairing code); it shows these lines with your code filled in.

Mac or Linux (Terminal):

curl -fsSL "/install.sh?code=CODE" | sh

Windows (PowerShell):

irm "/install.ps1?code=CODE" | iex

It installs Infera and Ollama, pairs this computer, picks the best models for your hardware (plus text to speech, text to video and fast transcription on NVIDIA GPUs with 8 GB+), downloads them, benchmarks, and starts Infera in your menu bar / system tray at every login. Running it again is safe: it skips what's already installed.
