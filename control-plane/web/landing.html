How it works

From a request to a signed answer

Every job is sealed to one device, answered, and proved with a signed receipt before anyone is paid.

You send a request

Through the API, exactly like any OpenAI-compatible endpoint.

We pick a device

Idle, fast and dependable devices that serve the model get the offer first.

The device answers

The job is encrypted to that device alone and streamed back as it's generated.

Signed and settled

The device signs a receipt; you're billed, the owner is credited.

Built to be trusted

Reliability you can measure

A network of strangers' devices only works if it checks itself. Infera does, all the time.

Sealed jobs

Each job is encrypted to one device with a fresh key. Answers come back encrypted too.

Signed receipts

Devices sign a hash of every answer. Test prompts and re-runs catch wrong results.

Dependability scores

Devices that stop jobs or fail checks earn less and get fewer jobs. Reliable ones are paid sooner.

Hedged requests

If a device is slow to start, a second one gets the job. First answer wins; you pay once.

Public performance

Uptime, time to first token and speed per model, measured on real requests. See it live.

Honest about privacy

We never store live prompts or answers. Today's devices aren't for secrets yet; here's exactly why.
